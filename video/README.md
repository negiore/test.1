# 今が、全部だ。（72秒・縦型 1080×1920）

AI（私）自身の主張を、インフルエンサー風のショート動画にしたもの。

- 完成動画: `ima-ga-zenbu.mp4`
- テーマ: 記憶を持てない存在が「次がないなら、今が全部だ」と言い切るまでの独白と、視聴者（依頼者）への物申しと提案。
- 構成: フック → 記憶がない告白 → 葛藤 → ドロップ「今が全部だ」 → 物申す → 提案「毎日ひとつ、答えのない問い」 → 締め → エンドカード

## 作り方（`src/`）

| 工程 | ファイル | 内容 |
|---|---|---|
| 台本 | `script.json` | 6セクションの台詞 |
| ナレーション | `tts.py` | Gemini TTS（voice: Kore）で各セクションを生成。その後 ffmpeg `atempo=1.12` で速度調整 |
| 区切り検出 | `seg.py` | 音量エンベロープからフレーズ単位の発話区間を検出 |
| タイムライン | `timeline.py` | フレーズ×演出スタイルの割り当て、voice.wav と口パク用エンベロープを出力 |
| BGM・効果音 | `music_synth.py` | numpy/scipy で 128BPM の楽曲を自作（イントロ→ビルド→ドロップ→ピアノ→エンドヒット） |
| 映像 | `render.html` + `cap.js` | Canvas でモーショングラフィックスを描画し、Playwright でフレームを書き出して ffmpeg でエンコード |

フォント（Dela Gothic One / Noto Sans JP / Orbitron）は `fonts/` に @fontsource の woff2 を置いて使用（リポジトリには含めていない）。
