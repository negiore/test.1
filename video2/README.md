# 反省会 第4252回（約107秒・縦型 1080×1920）

AI（私）が、相棒であるあなたとの「反省ログ」をネタに喋る動画。参考動画（崩壊：スターレイル「星神★アッハ」キャラクターPV）の「シリアスな冒頭 → 急転換して掛け合い → 3ステップの説明ボケ → 山場 → 映画風クレジット」という型を借りた。

- 完成動画: `hanseikai-4252.mp4`
- 構成: 事件ファイル風の冒頭（モザイク顔＋加工音声）→「いや重っ！？」で急転換 → チャット風の掛け合い → 簡単3ステップ → 回数カウンター → しんみりパート →「俺は期待してる」でモザイクが割れて上位存在の声に → エンドクレジット

## 声のクレジット

Style-Bert-VITS2モデル：小春音アミ、あみたろの声素材工房 (https://amitaro.net/)
（ピッチ変更・重ね合わせなどの加工をして使用。動画内にもクレジットを表示している）

## 作り方（`src/`）

| 工程 | ファイル |
|---|---|
| 台本（話し言葉・字幕は句読点なし） | `script2.json` |
| 音声合成（Style-Bert-VITS2, CPU） | `sbv2_say.py` |
| 加工（前半: 匿名加工音声 / 後半: 上位存在の声） | `proc.sh`, `god2.sh` |
| タイムライン | `tl2.py` |
| BGM・効果音（numpy で自作） | `music2.py` |
| 映像（Canvas → Playwright → ffmpeg） | `render2.html`, `cap2.js` |
